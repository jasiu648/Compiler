Projekt przedstawia kompilator języka programowania CSoft, wzorowanego na C#, który lekko modyfikuje i upraszcza poszczególne jego operacje.

Język CSoft:
1. Obsługuje typy: int, long, double, string, bool
2. Jest dynamicznie typowany, ale można określić typ zmiennej przy deklaracji
3. Pozwala na opcje standarowego wejścia-wyjścia: print(), read()
4. Obsługuje podstawowe operacje arytmetyczne: +, -, *, /, %
5. Pozwala na dodawanie komentarzy jednoliniowych, poprzedzone symbolem '#'
6. Wskazuje błędy podczas analizy leksykalno-składniowej
7. Obsługuje tablice liczb całkowitych i zmiennoprzecinkowych
8. Obsługuje wyrażenia logiczne AND, OR, XOR, NOT
9. Pozwala na tworzenie instrukcji warunkowej if
10. Pozwala na tworzenie pętli repeat
11. Pozwala na definiowanie własnych struktur i klas
